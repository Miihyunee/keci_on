# KECI ON 출장 여비 계산기

한국환경보전원(KECI) 임직원의 국내 출장 여비를 여비규정에 따라 자동 계산하고, 출장자 여비 지급 명부를 PDF로 출력하는 단일 페이지 웹 애플리케이션입니다.

---

## 파일 구성

```
index.html   — 페이지 전체 마크업 및 레이아웃
style.css    — KECI ON 디자인 시스템 기반 스타일
script.js    — 여비 계산 로직, UI 제어, PDF 출력
```

외부 라이브러리는 CDN으로만 로드하며 별도 빌드 도구가 필요 없습니다.

| 라이브러리 | 용도 |
|---|---|
| Pretendard / Inter | 웹폰트 |
| Font Awesome 6 | 아이콘 |
| html2canvas 1.4.1 | 테이블 캔버스 렌더링 |
| jsPDF 2.5.1 | PDF 파일 생성 |

---

## 화면 구성

### 레이아웃
- **사이드바** (좌측 260px) — KECI ON 로고, 기관명 표시. 인쇄·PDF 시 숨김.
- **상단 내비게이션 바** — 프로토타입 안내 문구 표시. 인쇄·PDF 시 숨김.
- **메인 콘텐츠** — 입력 카드, 실시간 대시보드, 명부 테이블, 액션 버튼.

### 입력 카드 (`section.card`)

입력 영역은 세 개의 섹션으로 구분됩니다.

**① 기본 복명 정보**

| 필드 | ID | 설명 |
|---|---|---|
| 출장자 | `name` | 출장자 성명 (명부 등록 필수) |
| 직급 | `role` | 원장~기간제 13단계 선택 (현재 계산 로직과 직접 연동 없음, 명부 참고용) |
| 출장지 | `destination` | 목적지 텍스트 (명부 등록 필수) |
| 출장 기간 | `dateStart` / `dateEnd` | 시작·종료일 날짜 선택. 페이지 로드 시 오늘 날짜 자동 설정. 선택 후 라벨에 **n박 m일 / 당일(1일)** 표시 |
| 출장 용무 | `purpose` | 용무 텍스트 (참고용) |

**② 여비 적용 조건**

| 필드 | ID | 선택지 | 영향 |
|---|---|---|---|
| 출장 권역 구분 | `tripType` | 근무지 내(4시간 미만) / 근무지 내(4시간 이상) / 근무지 외 | 일비·식비 기준액 결정 |
| 해당 직급 등급 | `grade` | 제1호(원장/임원) / 제2호(일반 직원) | 숙박비 상한 안내 참고용 |
| 도착 권역 지자체 | `region` | 서울·광역시·대전·기타 | 숙박비 상한 안내 참고용. **근무지 외**일 때만 표시 |
| 지원 이동차량 구분 | `vehicle` | 업무용 공용차량 / 일반 대중교통 / 자가용 / 관용차량 | 일비 50% 감액 여부 결정. 대중교통 선택 시 주유·주차·하이패스 필드 비활성화 |

**③ 여비 가감 및 실비 정산**

| 필드 | ID | 설명 |
|---|---|---|
| 숙박비 (개인) | `lodgingPersonalNights` / `lodgingPersonalAmount` | 박 수 + 금액. 당일 출장 시 자동 초기화 |
| 숙박비 (법인) | `lodgingCorpNights` / `lodgingCorpAmount` | 법인카드 결제분 |
| 식사 제공 공제 | `freeMeals` | 제공 횟수당 8,300원 공제 (근무지 외일 때만 적용) |
| 기본 여객 운임비 | `transportFarePersonal` / `transportFareCorp` | 대중교통 개인·법인 |
| 업무 주유 정산비 | `transportFuelPersonal` / `transportFuelCorp` | 대중교통 선택 시 비활성. 라벨 옆 **유류비 계산기** 버튼으로 오피넷 연동 자동 계산 패널 오픈 (아래 "유류비 자동 계산기" 절 참고) |
| 시설 유료 주차비 | `transportParkingPersonal` / `transportParkingCorp` | 대중교통 선택 시 비활성 |
| 하이패스 통행요금 | `transportHipassPersonal` / `transportHipassCorp` | 대중교통 선택 시 비활성 |

## 여비 계산 규칙

모든 계산은 `updatePreview()` 함수 안에서 실시간으로 수행됩니다.

### 출장 일수

```
일수 = (종료일 - 시작일) + 1
```

### 일비

| 조건 | 기준 일비 |
|---|---|
| 근무지 외 | 25,000원 |
| 근무지 내 (4시간 이상) | 20,000원 |
| 근무지 내 (4시간 미만) | 10,000원 |

업무용 공용차량 / 자가용 / 관용차량 이용 시 → **기준 일비 × 50%** 감액

```
일비 합계 = 기준 일비 × 출장 일수
```

### 식비

| 조건 | 기준 식비 |
|---|---|
| 근무지 외 | 25,000원/일 |
| 근무지 내 (4시간 이상 / 미만) | 0원 |

```
식비 합계 = (25,000 × 출장 일수) − (식사 제공 횟수 × 8,300원)
            단, 음수가 되면 0원으로 처리
```

### 숙박비

입력된 개인 금액 + 법인 금액의 합산. 직접 입력 방식(실비 정산)이며, 당일 출장(시작일 = 종료일)이면 입력값이 자동으로 초기화됩니다.

숙박비 상한 기준 (제2호 직원 기준):

| 지역 | 상한 |
|---|---|
| 서울특별시 | 100,000원/박 |
| 광역시 | 80,000원/박 |
| 그 밖의 지역 | 70,000원/박 |

제1호(원장·임원)는 실비 정산.

### 교통비

개인 결제분 4개 항목 합계 + 법인 결제분 4개 항목 합계.

### 여비 합계

```
여비 합계 = 일비 + 식비 + 숙박비(개인+법인) + 교통비(개인+법인)
```

## 실시간 대시보드

입력값이 바뀔 때마다 `#costDashboardContainer` 안의 카드 5개가 즉시 갱신됩니다.

```
[ 일비 ] [ 식비 ] [ 숙박비 ] [ 교통비 ] [ 여비합계 ]
```

일비·식비는 개인 항목이므로 단일 금액 표시. 숙박비·교통비는 개인+법인 합산 금액 표시. 여비합계 카드는 파란색 강조 배경으로 구분됩니다.

## 출장자 여비 지급 명부

### 데이터 추가

"명부에 데이터 추가" 버튼 클릭 시 `addRoster()` 실행.

필수 입력 항목 누락(성명, 출장지, 시작일, 종료일) 시 경고 후 중단.

명부 테이블 컬럼 구성:

| 성명 | 출장지 | 기간 | 일비 | 식비 | 숙박비 | 교통비 | 총액 | 관리 |
|---|---|---|---|---|---|---|---|---|

- 일비·식비: 개인 항목이므로 단일 금액 표시
- 숙박비·교통비·총액: 셀 내부에 **(개인) n원 / (법인) n원** 2줄로 표시
- 기간: `YYYY/MM/DD ~ YYYY/MM/DD` 형식
- 관리: 행 삭제 버튼 (인쇄·PDF 시 숨김)

### PDF 출력

"PDF 파일 다운로드" 버튼 클릭 시 `generatePDF()` 실행.

1. 테이블 상단에 `□ 출장별첨` 헤더, 하단에 여비규정 주석 문구를 임시로 표시
2. `.no-print` 요소(삭제 버튼 등) 임시 숨김
3. 테이블 너비를 1200px로 고정하여 가로 스크롤 없이 캡처
4. `html2canvas`로 캔버스 렌더링 (scale: 2, 고해상도)
5. A4 가로(landscape) jsPDF로 변환, 페이지 넘김 처리
6. `출장별첨_여비지급명부.pdf` 로 저장
7. 캡처 후 DOM 원복

## 유류비 자동 계산기 (한국석유공사 오피넷 Open API 연동)

"업무 주유 정산비" 라벨 우측의 **유류비 계산기** 버튼(`toggleFuelCalc()`)을 누르면 계산 패널이 열립니다. 대중교통 이용 시에는 버튼이 비활성화되고 패널이 자동으로 닫힙니다(`onVehicleChange()`에서 처리).

### 계산 방식

```
예상 유류비 = (이동 거리 ÷ 차량 연비) × 리터당 단가
```

- **리터당 단가**는 오피넷 API로 자동 조회하거나 직접 입력할 수 있습니다.
- 계산 결과는 "개인 정산비에 반영" / "법인 정산비에 반영" 버튼으로 `transportFuelPersonal` / `transportFuelCorp` 입력값에 **더해서** 반영됩니다(기존 입력값 보존).

### 오피넷 API 연동

| 항목 | 내용 |
|---|---|
| 사용 API | 오피넷 전국 주유소 평균가격 (`avgAllPrice.do`) |
| 요청 URL | `https://www.opinet.co.kr/api/avgAllPrice.do?out=json&code={인증키}` |
| 인증키 발급 | [오피넷 API 신청 페이지](https://www.opinet.co.kr/user/custapi/custApiInfo.do) (회원가입 후 무료 발급) |
| 지원 유종 | 휘발유(B027) · 경유(D047) · 고급휘발유(B034) · LPG(K015) |
| 인증키 저장 위치 | 브라우저 `localStorage`(`opinetApiKey`)에만 저장. 서버로 전송되지 않음 |

`fetchOpinetPrice()`가 위 URL을 호출해 응답(JSON)의 `RESULT.OIL` 목록에서 선택한 유종의 `PRICE`(리터당 평균가)를 찾아 "리터당 단가" 입력란에 채워 넣고, `updateFuelCalcResult()`가 계산 결과를 갱신합니다.

> ⚠️ **CORS 관련 주의사항**: 이 프로젝트는 백엔드가 없는 순수 정적 페이지이므로 오피넷 API를 브라우저에서 직접 호출합니다. 오피넷 서버가 브라우저 간 교차 출처 요청(CORS)을 허용하지 않는 경우 조회가 실패할 수 있으며, 이 경우 안내 메시지가 표시됩니다. 이때도 "리터당 단가"를 직접 입력하면 계산기 자체는 동일하게 동작합니다. 안정적인 자동 조회가 꼭 필요하다면 오피넷 API를 대신 호출해주는 별도의 서버(프록시)를 두는 방법이 있습니다.

> ℹ️ 오피넷이 제공하는 값은 **전국 평균가**이며, 실제 주유소 판매 가격과 다를 수 있는 참고용 수치입니다.

## 이벤트 흐름

```
페이지 로드
  └─ DOMContentLoaded
       ├─ dateStart / dateEnd = 오늘 날짜 세팅
       ├─ onDateChange()  →  updatePreview()
       ├─ onVehicleChange()  →  updatePreview()
       └─ onTripTypeChange()  →  updatePreview()

날짜 변경 (onchange)
  └─ onDateChange()
       ├─ 역방향 날짜 유효성 검사 (종료 < 시작 → alert + 보정)
       ├─ 당일 출장 시 숙박비 자동 초기화
       └─ updatePreview()

권역 변경 (onchange)
  └─ onTripTypeChange()
       ├─ 근무지 내: 도착 권역 지자체 필드 숨김
       ├─ 근무지 외: 도착 권역 지자체 필드 표시
       └─ updatePreview()

차량 변경 (onchange)
  └─ onVehicleChange()
       ├─ 대중교통: 주유·주차·하이패스 필드 비활성화 + 초기화
       ├─ 그 외: 해당 필드 활성화
       └─ updatePreview()

updatePreview() — 모든 변경의 최종 수렴점
  ├─ 출장 기간 라벨 갱신 (n박 m일 / 당일 1일)
  ├─ 일수 계산
  ├─ 일비·식비 계산
  ├─ 숙박비·교통비 집계
  ├─ 교통비 누적 합계 표시 (#transportTotalDisplay)
  ├─ 숙박비 입력값 안내 문구 (#lodgingPreviewText)
  └─ 대시보드 카드 5개 HTML 재렌더링 (#costDashboardContainer)
```

## 유틸리티 기능

**시뮬레이션 샘플 로드** (`loadSampleData`)
홍길동 / 정부세종청사 / 2026-07-14~16 / 근무지 외 / 대중교통 / 숙박 개인 14만원 / 운임 3.5만원 샘플 데이터를 자동 입력합니다.

**서식 초기화** (`resetForm`)
모든 입력 필드를 초기 상태로 되돌립니다. 날짜 필드는 오늘 날짜로, 나머지 입력값은 빈 칸으로, 차량은 대중교통, 권역은 근무지 외로 복원됩니다.

## 주요 설계 결정 사항

- **일비·식비는 개인 항목 전용.** 법인카드로 처리되는 항목이 아니므로 개인/법인 구분 없이 단일 값으로 표시합니다.
- **숙박비·교통비는 개인/법인 분리 입력.** 실비 정산 시 법인카드 사용 여부가 다를 수 있어 두 계정을 별도 관리합니다.
- **명부 테이블은 누적 방식.** 동일 세션에서 여러 출장자를 순차적으로 입력 후 한 번에 PDF로 출력합니다.
- **백엔드 없음.** 모든 계산과 상태는 브라우저 메모리에서만 처리되며 페이지를 새로 고치면 초기화됩니다.
- **인쇄/PDF 이원화.** 브라우저 인쇄(`@media print`)와 html2canvas+jsPDF 방식 모두 지원하며, `.no-print` 클래스로 출력 제외 요소를 공통 관리합니다.
