# 🌐 내 웹 프로젝트

깃허브 관리를 위해 컴포넌트별(HTML, CSS, JS)로 분리하여 설계된 프로젝트 저장소입니다.

## 📁 파일 구조
* `index.html` - 웹페이지 구조 및 레이아웃
* `style.css` - UI/UX 디자인 및 레이아웃 스타일링
* `script.js` - 인터랙티브 기능 및 이벤트 제어

## ⚙️ 시작하기
1. 이 저장소를 클론(Clone)하거나 다운로드합니다.
2. 가지고 계신 로고 이미지를 이 디렉토리에 복사한 후 이름을 `logo.png`로 변경합니다.
3. `index.html` 파일을 브라우저로 열어 실행을 확인합니다.
